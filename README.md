# ELENA MIRONOVA — Interior Designer Portfolio

Демонстрационный сайт частного интерьерного дизайнера. Проект создан для frontend-портфолио и не представляет реальный бизнес или заказчика.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive layout
- Editorial portfolio design
- Project image viewer
- Accessible mobile navigation
- Form validation
- Responsive WebP images
- Accessibility / reduced motion
- GitHub Pages compatible

Форма демонстрационная: данные не отправляются и не сохраняются. Исходные фотографии сохранены отдельно от оптимизированных WebP.

## Локальный запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## GitHub Pages

Поместите файлы проекта в корень репозитория. В **Settings → Pages** выберите **Deploy from a branch → main → /(root)**.

Все ресурсы используют относительные пути, совместимые с размещением в подпапке репозитория.
